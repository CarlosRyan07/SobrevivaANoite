# Evidências do projeto

Esta pasta reúne capturas selecionadas para demonstrar a qualidade e as principais funcionalidades de **Sobreviva à Noite**.

## Organização

- `qa/`: resultados de testes, cobertura e validações automatizadas;
- `funcionalidades/`: telas e fluxos representativos do jogo.

## Padrão dos arquivos

- usar letras minúsculas e nomes em `kebab-case`;
- não usar espaços, acentos ou nomes genéricos como `print1.png`;
- usar `.png` para preservar a leitura de textos e resultados do terminal;
- manter data, commit e comando na documentação, não no nome do arquivo;
- substituir a captura quando o resultado for atualizado, preservando o nome e os links.

As imagens públicas não devem revelar cenas, nomes ou artes dos finais. A galeria pode aparecer somente no estado em que todos eles estão bloqueados.

Relatórios gerados (`coverage/`, traces, vídeos e artefatos completos) não devem ser versionados. Somente evidências selecionadas entram aqui.
